# Contributing

Thank you for helping improve ExceptionOps AI.

## Development principles

- Keep changes focused and documented.
- Add tests for new behavior and bug fixes.
- Keep deterministic business rules independent of the live AI provider.
- Do not commit secrets, real customer/supplier data, or confidential employer material.
- Document new configuration variables in `.env.example` using placeholders only.
- Do not claim accuracy, security, or production readiness without evidence.

## Planned workflow

1. Create a focused branch.
2. Describe the problem and expected behavior.
3. Implement the smallest suitable change.
4. Add or update tests.
5. Run the relevant checks.
6. Update documentation.
7. Open a pull request with test evidence.

The detailed commands will be added as implementation tooling is introduced in later phases.
